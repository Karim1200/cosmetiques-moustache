# Cosmétiques Moustache — دليل الموقع وإدارة المنتجات

## الملفات المهمة
- `index.html`: واجهة الزبائن.
- `style.css`: التصميم.
- `script.js`: البحث والتصفية وروابط WhatsApp وFacebook.
- `products-data.js`: بيانات المنتجات التي يقرأها الموقع.
- `admin.html`: لوحة بسيطة لإضافة وتعديل وحذف المنتجات والصور والأسعار.
- `assets/`: مجلد الصور (يمكن استخدامه عند التعديل اليدوي).

## إضافة المنتجات بالواجهة
1. افتح `admin.html` بالنقر المزدوج في المتصفح.
2. من نموذج **Ajouter un produit** أدخل اسم المنتج، التصنيف، السعر بالدينار، التفاصيل، والوسم الاختياري.
3. اضغط على **Photo du produit** لاختيار صورة من جهازك. الصور JPG وPNG وWebP حتى 4MB.
4. اضغط **Ajouter le produit**.
5. لإجراء تغييرات لاحقة، اضغط **Modifier** بجانب المنتج. ويمكنك حذفه بواسطة **Supprimer**.
6. بعد إكمال جميع المنتجات اضغط **Exporter products-data.js**. سيُحمّل المتصفح ملفًا بهذا الاسم.
7. انسخ الملف المحمّل إلى مجلد الموقع واستبدل الملف القديم `products-data.js`.
8. افتح `index.html` للتأكد من المنتجات والصور، ثم أعد رفع ملفات الموقع إلى الاستضافة كي تظهر التغييرات للزوار.

**مهم:** لوحة الإدارة لا تغيّر ملفات الموقع تلقائيًا ولا تحدّث الموقع المنشور مباشرة. المتصفح لا يسمح لصفحة ويب بالكتابة فوق ملفات الموقع لأسباب أمنية؛ لذلك يجب تصدير `products-data.js` ثم استبداله وإعادة النشر. بيانات المسودات تحفظ في نفس المتصفح فقط. احتفظ دائمًا بنسخة من الملف المصدر.

## إعداد WhatsApp وFacebook
افتح `script.js` وعدّل هذا الجزء:
```js
const STORE = {
  whatsappNumber: "213000000000",
  facebookPage: "https://www.facebook.com/",
  currency: "DA"
};
```
استبدل رقم WhatsApp برقمك الدولي، أرقام فقط دون + أو مسافات، واستبدل رابط Facebook برابط صفحتك الحقيقية. لا تنشر الموقع قبل تعديلهما.

## نشر الموقع مجانًا عبر GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كل ملفات الموقع والمجلدات، واجعل `index.html` في الجذر.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
5. بعد كل تعديل للمنتجات، استبدل `products-data.js` في المستودع بالنسخة الجديدة وارفع التغيير.

## ملاحظات
- المنتجات الأولية والأسعار مجرد أمثلة، والصور التجريبية قد لا تكون موجودة؛ أضف صورك الحقيقية من لوحة الإدارة.
- الموقع للعرض والتواصل فقط، ولا يتضمن الدفع الإلكتروني.
- يفضّل ضغط صور المنتجات لتسريع تحميل الموقع.
