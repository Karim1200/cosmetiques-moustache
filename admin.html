Gestion de la boutique

Connectez-vous pour ajouter, modifier ou supprimer les produits en ligne. Les changements sont enregistrés directement dans Supabase.

Configuration Supabase manquante. Ouvrez supabase-config.js et remplacez l'URL du projet et la clé anon/publishable par celles de votre projet Supabase, puis republiez les fichiers.

Connexion administrateur

Le compte doit être créé dans Supabase Authentication et autorisé dans la table admin_users. Aucun compte public ne peut s'inscrire depuis cette page.

Les photos sont envoyées dans le stockage Supabase. Les règles de sécurité de la base vérifient les droits du compte administrateur.
